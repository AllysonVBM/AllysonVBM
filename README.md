### 🚀 Projeto em Destaque

**Acardia — Sistema Multi-Agente com Memória e Auto-Reflexão**
Arquitetura multi-agente com pipelines assíncronos (Python/asyncio) e roteamento de LLM com failover entre provedores. Memória em múltiplas camadas via RAG (ChromaDB), com mecanismo de auto-reflexão para aprendizado contínuo sem necessidade de fine-tuning. Integração com Node.js (Mineflayer), utilizando o Minecraft como ambiente de simulação para testes de comportamento dos agentes.
